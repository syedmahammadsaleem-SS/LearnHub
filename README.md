## 🚀 Run Locally

```bash
git clone https://github.com/<your-username>/<your-repo>.git
cd <your-repo>
```

Open the folder in VS Code, install the **Live Server** extension, then right-click `index.html` and choose **Open with Live Server**. You can also run `python -m http.server 8000` and visit `http://localhost:8000`.

---

## 🌐 Deployment

The site is static, so it can be hosted for free.

**Netlify:** choose **Add new site → Deploy manually** and drag the project folder in, or connect the GitHub repo for automatic deploys.

**GitHub Pages:** enable **Settings → Pages** and select your branch.

---

## ✏️ Customizing This Portfolio

If you'd like to reuse the layout:

1. Replace the name, headline and about text in `index.html`.
2. Update the skills, projects, experience and education sections.
3. Change the email address used by the contact form.
4. Replace images, links and the resume file.
5. Adjust colors and fonts in `css/style.css`.
